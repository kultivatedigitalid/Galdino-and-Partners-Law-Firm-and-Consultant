# Visual revision — 29 September 2026

This revision implements the latest supplied design brief while retaining the approved Home composition and Profile hero/company/team foundations. The latest approved catalogue (38 services, six categories, four environmental groups, six industries) supersedes the older counts in the pasted design reference.

## Implementation

- Services: dark photo/document hero, search immediately after the banner, intent/synonym and partial-word recommendations, six category links with minimum indicative prices, three scenario entry panels, five-step pathway, related industries and insights. The full service directory lives in each category/group page; the hub reveals matching entries only when searched. Search scores are deterministic and local; they are navigation assistance, not a regulatory determination.
- Industries: photographic sector hero, sector index, asymmetric 1/2/3 image composition, landscape diagram, manufacturing preview, service/case/insight links. Details connect sector triggers, records, workflows and a consultant.
- Cases: image-led featured story with industry/service/stage filters, two medium and three compact photographic entries. Every case detail includes a hero, separate supporting image, structured metadata, pathway, deliverables and related content. No fabricated success percentages were added.
- About: existing hero, company statement and team preserved; founder note, provisional milestones, numbered principles, candid work strip and two case previews added.
- Logo: proportional header/footer sizing uses width with automatic height. Small WebP variant avoids downloading a 155 KB source for a small mark; favicon uses contain sizing in a square canvas.
- Accessibility: semantic headings, visible labels, live result counts, keyboard-native buttons/selects, reduced-motion rules, image alternatives and preserved focus behavior.
