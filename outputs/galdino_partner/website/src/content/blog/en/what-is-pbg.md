PBG, or building approval, forms part of readiness to build. Start the discussion with the location, intended use and proposed changes so technical records describe the same project.

## What should be mapped?

Record whether the work involves a new building, changes, an extension or a different use. Prepare the area, floor count, room uses and relationship to access and supporting facilities. This summary gives the team context before a document checklist is prepared.

## Keep technical records consistent

Architectural, structural and utility drawings need to align. Differences in area or use between land records, site plans and drawings can raise questions during review. Identify one reference version and track each revision.

Appropriate technical professionals must review their own disciplines. Administrative coordination supports completeness but does not replace technical design or accountability.

## Review location dependencies

Spatial and environmental records are important when mapping prerequisites. SIMBG describes prerequisite documents for applications. The correct conditions and pathway must still be assessed against the actual site and activity.

Do not set a construction schedule solely from an administrative estimate. Drawing corrections, information gathering and review time vary between projects.

## How does PBG relate to SLF?

Approval readiness for construction and fitness for occupancy are different questions. Preserve records from the design stage so the completed building can be traced when preparing a functional-fitness review.

Begin consultation with a project summary and available-document list. The team can then distinguish information gaps, technical work and the next steps.
